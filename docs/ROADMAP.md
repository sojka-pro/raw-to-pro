# Roadmap

## 0.1 — MVP

- wejście RAW i opcjonalny kontekst;
- profile dla chatów, agentów kodujących i grafiki;
- poziomy Szybki / PRO / MASTER;
- kopiowanie wyniku;
- polski i angielski;
- serwerowe OpenAI API.

## Kandydaci po walidacji MVP

- lokalna historia bez synchronizacji;
- eksport Markdown i JSON;
- własne profile narzędzi;
- tryb porównania dwóch wariantów;
- ewaluacje jakości promptów;
- adaptery innych dostawców.
