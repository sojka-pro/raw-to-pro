# MAGICK//AI OS .PRO — extension roadmap

The Base Codex remains complete. .PRO should add leverage, libraries and automation rather than remove essential practice from the base edition.

## Candidate .PRO modules

1. **Ritual Composer** — guided builder for intention, method, safety checks and printable operation cards.
2. **Symbol Lab** — sigil variants, visual prompt packs and a personal symbol dictionary.
3. **Oracle Decks** — reusable symbolic prompt decks with explicit non-predictive interpretation rules.
4. **Local Vault** — encrypted or local-first session archive and search.
5. **Result Analytics** — timelines, tags, baseline/result comparison and bias-aware review.
6. **Knowledge Library** — sourced notes on chaos magick history, terminology, creators and adjacent psychological concepts.
7. **Experiment Engine** — one-variable personal belief and attention experiments.
8. **Operator adapters** — ChatGPT Work, OpenCode and future agent profiles.
9. **Export Studio** — Markdown, PDF, cards and booklet formats in PL and EN.
10. **Personal Protocol Builder** — user-defined commands, modes and templates.

## Product rule

Never paywall:
- safety rules;
- epistemic labeling;
- the core RAW → AUDIT loop;
- basic journaling;
- the ability to close or review an operation.

.PRO is premium because it saves time, adds depth and organizes data — not because the base user receives an intentionally broken system.
